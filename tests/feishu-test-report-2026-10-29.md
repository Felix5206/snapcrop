## 经验沉淀（可复用要点）

1. 进度条字段取值域为 0~1 小数，写入 50 会报"字段形状不匹配"——并非字段名错误
2. 单选字段传不存在选项报 `not_found`，属正常校验行为
3. PowerShell 5.1 下中文/复杂 JSON 一律写文件后 `--json @file` 传参（UTF-8 无 BOM），避免内联引号被吞
4. 关联字段必须先建目标记录拿到 record_id 再写入；失效 id 不会被平台拦截
